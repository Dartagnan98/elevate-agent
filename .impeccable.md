## Design Context

### Users

Elevate is for working real estate agents who use the desktop app during active client, lead, listing, and transaction work. They need to select their province once, receive the correct provincial transaction pack automatically, understand required documents, delegate concrete work to the right agent and tools, review sensitive actions, and return to long-running sessions without losing progress or wondering what actually happened.

### Brand Personality

Realtor-friendly, calm, and dependable. The product should create confidence through plain language, accurate status, visible next steps, and professional restraint. It must never feel like a developer terminal, a generic AI dashboard, or an opaque autonomous system that claims success without proof.

### Aesthetic Direction

Preserve Elevate's existing realtor-facing application identity and current theme system rather than redesigning the product. Favor a focused, operational workspace: clear hierarchy, recognizable real-estate language, legible dense information, quiet status color, and progressive disclosure for advanced harness details. Desktop is the primary context, with supported responsive layouts and complete keyboard, zoom, reduced-motion, and screen-reader behavior. Both existing supported themes must remain coherent wherever they are exposed.

### Design Principles

1. Truth before polish: visible state must come from canonical persisted facts, and success must include evidence.
2. Realtor language first: lead with deals, clients, documents, approvals, deadlines, and next actions; keep harness internals secondary.
3. One obvious next step: every view and empty state should make the safe next action clear.
4. No dead or deceptive controls: every interactive surface must work, be disabled with a useful reason, or be hidden.
5. Calm under failure: loading, offline, stale, partial, blocked, and error states must preserve context and explain recovery without blame.
6. Accessible by default: complete keyboard use, visible focus, semantic controls, adequate contrast, zoom resilience, reduced motion, and screen-reader names are release requirements.
