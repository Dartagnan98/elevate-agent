# British Columbia residential resale reference guide

This bundled guide is a workflow aid for a licensed real estate professional. It is reference only, its current version is unverified, and it is not legal or brokerage advice.

## Non-negotiable document rule

- Every catalog entry is provider required. The catalog identifies a possible document; it does not contain a blank form, form wording, field map, signature coordinate, or completed example.
- Obtain the current licensed blank from the realtor's configured forms provider or brokerage library before drafting anything.
- Confirm the current form version, transaction fit, brokerage policy, board requirements, and required signers before use.
- If a licensed blank or required transaction fact is missing, pause and report the exact gap. Never invent wording, fields, initials, signatures, dates, or completion evidence.
- Drafting and package assembly remain reviewable work. External delivery, signing, submission, and filing require the configured human approval.

## Residential resale workflow

### Start with the deal facts

Confirm the side represented, property type, ownership, client legal names, brokerage and board context, agency relationship, occupancy, tenancy, strata status, material dates, deposit instructions, and any assignment or First Nations leasehold considerations. Record unknowns as unknowns.

### Choose candidates, not conclusions

Search the catalog by form code, title, category, transaction side, and the facts above. Return a short candidate list with the reason each item may apply. A catalog match is never proof that a form is required or current.

### Acquire and verify the licensed blank

Use the configured forms provider. Confirm the blank's title and version with the provider and brokerage instructions. If the provider is unavailable or the blank cannot be verified, stop the document task and request the missing access or human decision.

### Prepare a reviewable draft

Populate only facts supported by the deal record or an explicit human answer. Keep unresolved fields visible. Do not copy clauses from memory. Use brokerage-approved clauses and instructions through the configured provider.

### Review before action

Present the selected forms, unresolved facts, material dates, parties, and intended next action. Obtain the required approval before sending for signature, uploading to a portal, changing MLS data, or communicating with a client.

### Prove completion

Report a document step complete only after the expected artifact or provider confirmation exists and can be inspected. State what was created, where it is stored, what remains unsigned or unsubmitted, and the next required action.

## Search guidance

When using document search, include British Columbia, the transaction side, the form code or purpose, and the relevant property facts. Search results from this pack are guidance and catalog metadata only. They never replace the licensed blank or a provider-side version check.
